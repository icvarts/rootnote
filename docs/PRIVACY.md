# 数据与操作边界

## 读取

| 数据 | 用途 | 说明 |
| --- | --- | --- |
| 系统内存、交换内存、压缩内存 | 性能提示 | 本机只读 |
| 本机 Codex 数据库、打开的会话路径、文件体积 | 会话列表、风险判断 | 依赖客户端的本地数据格式 |
| 会话事件日志的近期片段 | 任务状态与环境场景 | 在内存解析；包括工具名、参数及结果片段，不宣称完全不读取内容 |
| 客户端宠物位置、可见性与设置 | 桌面锚点和动画生命周期 | 不修改客户端配置 |
| 辅助功能侧栏结构、账号按钮与边界 | 侧栏胶囊定位与碰撞检查 | 不发送点击、不导出界面树，不记录账号按钮内容 |
| 宿主 `config.toml` 中 `[desktop]` 的外观模式及主题背景色 | 胶囊深浅适配 | 只提取所需字段，不改写或导出配置；不支持格式时停止显示 |
| Codex CLI 的账号和额度接口 | 额度展示 | 只读请求，不处理认证文件；CLI 可能访问 OpenAI 服务 |

## 保存

- 脱敏账号标识、额度快照、提醒及外观偏好：`~/Library/Application Support/Rootnote/Panel`。
- 环境暂停偏好由 macOS 偏好系统保存；窗口定位和场景运行回执使用临时目录。
- 输入草稿保留在当前页面内存；点击复制时写入系统剪贴板，剪贴板受系统及用户剪贴板工具管理。
- 不保存完整会话副本，不收集密码或令牌，不设置 Rootnote 云端遥测服务。

## 不执行

不自动归档任务、删除会话、释放内存、结束进程、切换账号、使用额度重置机会或代替用户批准权限。
跟进操作只复制内容并打开指定会话，最终发送由用户完成。
历史审批桥保留为禁用的兼容源码；默认发布配置关闭原生控件桥，缺少共享接口时不执行审批。

## 发布与反馈

仓库只包含源码、授权素材、许可证及合成测试数据，不包含维护者的本地账号记录、认证文件、对话日志或安装恢复包。
提交反馈前删除会话名称、文件路径、邮箱、令牌和客户内容。
不要把真实会话日志直接附到公开 Issue。

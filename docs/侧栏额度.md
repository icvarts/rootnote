# 侧栏额度

在兼容的 Codex / ChatGPT 桌面客户端左侧导航条底部查看周额度，无须先显示宠物。
这是一块由 Rootnote 绘制并跟随宿主窗口的独立浮层，不是 Codex 原生侧栏扩展。

## 使用

1. 打开 Rootnote；在 macOS「系统设置 → 隐私与安全性 → 辅助功能」中允许 Rootnote。
2. 将兼容客户端置于前台，展开侧栏。识别到导航条和账号按钮、且约定区域没有遮挡时显示胶囊。
3. 点击胶囊打开现有面板的「额度」页，再点一次关闭。性能圈与侧栏使用同一个面板，两处均可关闭它。

宿主侧栏可用时入口持续显示。切换到其他应用、宿主最小化、侧栏不可用或位置被遮挡时隐藏；不会改放到其他位置。
开关面板不会召唤或隐藏宠物。打开面板默认不激活 Rootnote；编辑控件可按需取得键盘焦点，输入和复制继续可用。

## 展示与点击范围

| 项目 | 行为 |
| --- | --- |
| 周额度 | 仅显示当前账号、接口明确返回的每周窗口；过期、同步中或不可用时显示「待同步」 |
| 对齐 | 跟随已识别导航条的水平中心，位于账号按钮上方 12 pt |
| 底色 | 36 × 116 pt，无装饰描边；单层 95% 不透明度，环和文字保持完整不透明 |
| 点击 | 中间 28 × 96 pt；其余透明画布、圆角及上下装饰区域由原生窗口直接穿透 |
| 无障碍 | 保留键盘开关和焦点提示；开启系统「降低透明度」时使用实色底 |

胶囊独立于 Rootnote 面板自身的深浅选择。它只读宿主 `config.toml` 中 `[desktop]` 的外观模式和当前主题背景色，选择中性深色或浅色；宿主跟随系统时，再使用系统外观选择当前主题分支。不会复制所有自定义颜色，也不改写宿主配置。

主界面自定义深色背景与原生宠物提示条/输入条的材质可能不同。需要统一原生材质时，可使用宿主自己的外观设置选择深色模式；Rootnote 不会替用户修改全局外观，也不重绘输入、语音或活动提示控件。

## 数据与兼容性

辅助功能只用于识别侧栏结构、账号按钮和边界，不点击或修改宿主元素。账号数据沿用现有只读额度同步，不读取认证文件。
外观适配只提取模式和背景色，不导出主题配置；不支持的配置格式会暂停显示。

宿主窗口结构、主题字段和客户端安装路径属于兼容适配，不是稳定公开接口。当前仅实机验证 Apple Silicon / macOS 26 与兼容客户端；不同版本、旧 macOS、Intel、多显示器及长期运行仍需要进一步验证。
无法识别时使用菜单栏中的现有面板，不放宽账号/边界校验，也不修改宿主安装文件。
